# Today's meal

점심 메뉴처럼 선택하기 어려운 후보를 등록하고, 비율을 조절한 룰렛으로 무작위 선택을 돕는 반응형 웹앱입니다. HTML, CSS, JavaScript만으로 동작하며 후보와 설정은 브라우저에 저장됩니다.

## 링크

- **GitHub 저장소:** <https://github.com/lsc0772/vibe-midtern-202602406>
- **GitHub Pages 배포:** <https://lsc0772.github.io/vibe-midtern-202602406/>

## 주요 기능

- 후보 추가, 개별 삭제 및 전체 삭제
- 후보별 비율 설정(1~1000)과 실시간 당첨 확률 표시
- 비율에 따른 원판 크기와 가중치 무작위 추첨
- 룰렛 무한 회전 및 사용자가 누르는 정지 버튼, 감속 애니메이션
- 화살표가 가리키는 현재 후보 표시와 추첨 결과 오버레이
- 라이트/다크 테마와 데스크톱/모바일 화면 배치 전환
- 후보, 테마, 화면 배치 설정의 브라우저 저장

## 사용법

1. 후보 입력란에 메뉴를 입력하고 **추가**를 누릅니다. Enter 키로도 추가할 수 있습니다.
2. 각 후보 오른쪽의 비율을 조정합니다. 비율이 높을수록 당첨 확률이 올라갑니다.
3. **룰렛 돌리기**를 눌러 원판을 회전시킨 다음, 원하는 순간 **룰렛 멈추기**를 누릅니다.
4. 감속이 끝나면 화살표가 가리키는 후보와 중앙 결과 표시를 확인합니다.
5. 상단 버튼으로 라이트/다크 테마와 데스크톱/모바일 레이아웃을 바꿀 수 있습니다.

## 로컬에서 실행

별도 패키지 설치나 빌드 과정은 필요하지 않습니다. `index.html`을 브라우저에서 열면 사용할 수 있습니다.

```text
index.html
css/style.css
js/app.js
```
